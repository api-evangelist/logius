Logius is the digital government service organisation of the Dutch Ministry of the Interior and Kingdom Relations (Ministerie van Binnenlandse Zaken en Koninkrijksrelaties). It provides the shared ICT infrastructure and standards used by Dutch public service providers, including DigiD, eHerkenning, MijnOverheid, Digipoort, Digikoppeling, PKIoverheid and Standard Business Reporting, and it maintains the NL GOV REST API Design Rules and related API standards (with a Spectral linter ruleset) for the Dutch public sector.

**Areas:** Company · Government · Netherlands · API Standards · API Design Rules · Digital Identity · Data Exchange · Public Sector

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Logius: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
